RULER

NETWORK DEFENSE // LINUX ONLY
Ruler 👑 is a lightweight, high-performance network defense tool written in Go designed to confuse active reconnaissance and network mapping attempts.

Ruler dynamically binds and rotates a block of randomized decoy IP addresses on your network interface at custom intervals, protecting your system's real IP presence.

Generates and rotates a block of 10 randomized decoy IP addresses within an isolated private subnet block (10.255.254.x) to prevent ARP collisions. Customize with -interval flag to bypass IDS/IPS signature triggers.

Automatically validates interface and auto-purges all fake IP traces on Ctrl+C / SIGTERM. 
sudo ./ruler eth0
sudo ./ruler -interval 5 wlan0
sudo ./ruler -interval 1 eth0
