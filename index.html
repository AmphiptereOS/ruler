What is Ruler?

Ruler is an open-source Linux defense tool created by Amphiptere OS. It functions as a Secure Defense Layer and Fake IP Decoy System that implements Moving Target Defense (MTD) strategies to confuse network scanners, automated enumeration tools, and attackers performing reconnaissance.

About Ruler

Ruler protects a host by dynamically generating and continuously rotating a grid of fake secondary IP addresses on a specified network interface. This floods any active network mapping or sniffing tools with false data, obscuring the actual host footprint.

Key operational characteristics include:

  • Interface Validation: Verifies that the target network interface exists and is active (UP) before launching.
  • Decoy Generation: Automatically generates 10 randomized secondary IP addresses within a simulated subnet block (10.255.254.x).
  • Timed Rotation: Automatically cycles through the decoy grid at user-defined time intervals, dropping stale mock IPs and binding fresh ones.
  • Graceful Cleanup: Listens for termination signals (Ctrl+C) to instantly purge all decoy IP traces from the system, returning the interface to a clean, original state upon exit.

What Ruler Does

When an attacker runs nmap or any network mapper against your network, Ruler makes your single host appear as 11 hosts. The decoy grid rotates every few minutes, so scanners cannot fingerprint your real footprint. Your real IP gets lost in your own noise. It's Moving Target Defense for Linux.

How to Use Ruler

Ruler is executed via Go source (Ruler.go) and requires root privileges sudo to interact with the Linux kernel's network address tables. Works on AmphiptereOS, Debian, Kali, Ubuntu, Arch etc any Linux.

1. Basic Execution (Default 7 min rotation)

sudo go run Ruler.go <network_interface>

Example:
sudo go run Ruler.go eth0

2. Custom Interval Command

Run with custom rotation interval (e.g., every 5 minutes):

sudo go run Ruler.go -interval <minutes> <network_interface>

Example:
sudo go run Ruler.go -interval 5 wlan0

3. How to Customise Commands

# Rotate every 1 minute for aggressive defense
sudo go run Ruler.go -interval 1 eth0

# Rotate every 10 minutes for stealth labs
sudo go run Ruler.go -interval 10 wlan0

# Check if decoys are live
ip addr show eth0 | grep 10.255.254

# Stop and auto-clean (purges all fake IPs)
Ctrl + C
