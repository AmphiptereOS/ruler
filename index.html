RULER

NETWORK DECOY IP ROTATION TOOL

A lightweight defensive layer for AmphiptereOS. Ruler deploys a rotating grid of decoy IPs on your own interface to deceive network scanners and protect your real footprint. Built for Purple Team labs.

View on GitHub How to Use ↓

🛡️ Defensive, Not Offensive

Only adds private IPs (10.255.254.x) to YOUR OWN machine. Requires root. Cannot attack others. Auto-cleans on exit.

🔄 Rotating Grid

Creates 10 decoys and rotates them every 7 minutes (customizable). Scanners see a moving target, not your real host.

⚡ Built for AmphiptereOS

Written in Go, single binary, no dependencies. Works on eth0, wlan0, any Linux interface. Lightweight daemon.

What it does

When a scanner like Nmap does nmap -sn 10.255.254.0/24, instead of 1 host, it sees 10 fake hosts. Your real IP is hidden in noise. Perfect for SOC training, Honeypot labs, and Blue Team simulations.

Usage

sudo ./ruler eth0
sudo ./ruler -interval 5 wlan0   # rotate every 5 min

# verify
ip addr show eth0 | grep 10.255.254

# stop (auto-cleans)
Ctrl + C

Requirements

Linux + iproute2 + Root access. Part of AmphiptereOS ISO — already included in /opt/tools/ruler
