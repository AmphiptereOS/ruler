Complete Code Breakdown - Open Source - Written in Go

1. What is Ruler? (From Your Code)

From showBanner(): Ruler prints your ASCII banner with cyan color \033[36m. It's a daemon that lives on your interface and creates a Rotating Decoy Grid.

It is NOT an attack tool. It's a Moving Target Defense - it adds 10 fake IPs to confuse scanners.

2. Full Source Code Functions - Explained

func showBanner()

Prints the ASCII art logo: RULER. Uses ANSI escape codes for cyan color. First function called in main() to brand the tool.

func generateFakeIPs() []string

What it does: Creates 10 fake IPs.

r := rand.New(rand.NewSource(time.Now().UnixNano())) - seeds random with current time so every rotation is different.

fmt.Sprintf("10.255.254.%d", r.Intn(200)+10) - generates IPs from 10.255.254.10 to 10.255.254.209. You chose 10.255.254.0/24 because it's a rare, unused private subnet - smart, avoids conflict with home routers (192.168.1.x).

Returns []string slice of 10 IPs.

func validateInterface(ifaceName string) error

Security check before doing anything:

  • net.InterfaceByName(ifaceName) - checks if interface like eth0/wlan0 exists. If not, returns "interface does not exist".
  • iface.Flags&net.FlagUp == 0 - checks if interface is UP. If down, returns "interface is down".

This prevents crashing on wrong interface name.

func applyDecoys(iface string, oldIPs []string, newIPs []string)

This is the core engine:

1. First loop: ip addr del ip/24 dev iface - deletes old decoy IPs using Linux ip command via exec.Command.

2. Second loop: ip addr add ip/24 dev iface - binds new decoys. Prints [*] Deployed Decoy Active -> %s. If fails (not root), prints Are you root?.

func clearAll(iface string, ips []string)

Forensic cleanup handler. Called when you press Ctrl+C. Loops all current IPs and runs ip addr del. Prints Network restored to clean state. This is why your tool is safe - no ghost IPs.

func main() - Complete Flow

  1. Calls showBanner()
  2. Defines flag: flag.Int("interval", 7, "Rotation interval in minutes") - default 7 mins
  3. Parses args: expects <network_interface> like eth0. If missing, shows Usage: sudo go run main.go [options] <network_interface>
  4. Calls validateInterface()
  5. Creates signal channel: signal.Notify(sigChan, os.Interrupt, syscall.SIGTERM) to catch Ctrl+C
  6. Creates ticker: time.NewTicker(time.Duration(*intervalFlag) * time.Minute)
  7. Initial deploy: generateFakeIPs() + applyDecoys()
  8. Goroutine: for range ticker.C - every interval, generates new IPs and rotates
  9. Blocks on <-sigChan until you stop, then calls clearAll()

4. Requirements & Dependencies

From your imports: flag, fmt, math/rand, net, os, os/exec, os/signal, syscall, time

  • Go 1.19+
  • Linux with iproute2 installed (provides ip command)
  • Root access - because ip addr add needs root
  • Interface must be UP

5. Limitations in Current Version (v1)

  • Range is predictable: 10.255.254.10-209 only - I can improve to random across 3 private ranges
  • Uses exec.Command not netlink - slower
  • No log file
